# Student-Information-System

 Below is a simple **Student Information System** using **Java Swing**. It provides a graphical user interface (GUI) where users can **add**, **display**, **update**, and **delete** student records.  


 🖥️ **Features: 
✅ Add new student records (ID, Name, Age)  
✅ Display all student records in a table  
✅ Update existing student records  
✅ Delete student records
